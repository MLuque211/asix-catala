## Exercici 7: Operacions lògiques en sistema binari

Realitza les següents operacions bit a bit sobre els valors indicats:

* **a)** $100011011_2 \text{ OR } 100110110_2$
* **b)** $100011011_2 \text{ AND } 100110110_2$
* **c)** $\text{NOT }(10001101110_2)$
* **d)** $100011011_2 \text{ NAND } 100110110_2$
* **e)** $100011011_2 \text{ NOR } 100110110_2$

<details>
<summary><b>🔍 Veure repostes</b></summary>

* **a)** $100011011_2 \text{ OR } 100110110_2 = \mathbf{100111111_2}$
* **b)** $100011011_2 \text{ AND } 100110110_2 = \mathbf{100010010_2}$
* **c)** $\text{NOT }(10001101110_2) = \mathbf{01110010001_2}$
* **d)** $100011011_2 \text{ NAND } 100110110_2 = \mathbf{011101101_2}$
* **e)** $100011011_2 \text{ NOR } 100110110_2 = \mathbf{011000000_2}$
</details>
