# M05 - Gestió de Bases de Dades

Repositori dedicat al contingut, apunts, exercicis i pràctiques del mòdul **M05: Gestió de Bases de Dades** del cicle formatiu de grau superior (Perfil: Ciberseguretat / ASIX).

## Informació General
- **Mòdul:** M05
- **Perfil:** Ciberseguretat / ASIX
- **Descripció:** Disseny, implementació i consulta de bases de dades relacionals utilitzant el llenguatge SQL (MySQL, PostgreSQL, Oracle).

## Estructura del Mòdul

Aquest mòdul s'organitza en diferents Unitats Formatives (UF). A continuació es detallen els continguts i els Resultats d'Aprenentatge (RA) corresponents.

### UF1: Disseny i llenguatge SQL

#### Resultats d'Aprenentatge (RA)
- **RA1:** Reconeix els elements de les bases de dades analitzant les seves funcions i valorant la utilitat dels sistemes gestors.
- **RA2:** Dissenya models lògics normalitzats interpretant diagrames entitat-relació.
- **RA3:** Realitza el disseny físic de bases de dades utilitzant assistents, eines gràfiques i el llenguatge de definició de dades.
- **RA4:** Consulta la informació emmagatzemada emprant assistents, eines gràfiques i el llenguatge de manipulació de dades.
- **RA5:** Modifica la informació emmagatzemada emprant assistents, eines gràfiques i el llenguatge de manipulació de dades.
- **RA6:** Executa tasques d'assegurament de la informació, analitzant-les i aplicant mecanismes de salvaguarda i transferència.

- **[Pràctiques i Lliurables](./uf1/practiques/)**: Projectes, pràctiques d'avaluació i tasques a entregar.
