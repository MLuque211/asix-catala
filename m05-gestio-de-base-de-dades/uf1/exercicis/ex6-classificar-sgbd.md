<summary><b>🔍 Veure respostes</b></summary>

| SGBD | Model | Arquitectura típica | Ús habitual | Observacions |
| :---: |:---: |:---: |:---: |:---: |
| SQLite | Relacional | Encastat / Local | Aplicacions locals, mòbils, proves | No requereix servidor independent |
|MariaDB | Relacional | Client-servidor | Aplicacions web i empresarials | Fork/Derivat open source de MySQL |
| PostgreSQL | Relacional / Objecte-relacional | Client-servidor | Aplicacions empresarials, dades complexes, GIS | Molt extensible i robust amb estàndards SQL |
| MongoDB |	Documental (NoSQL) | Client-servidor / Distribuït | Documents JSON/BSON, grans volums de dades | Esquema flexible i fàcil d'escalar horitzontalment |
| Neo4j | Graf (NoSQL) | Client-servidor | Xarxes socials, recomanacions, relacions complexes | Optimitza consultes de camins i connexions |
| Redis | Clau-valor (NoSQL) | Client-servidor | Caching, gestió de sessions, cues simples | Treballa principalment en memòria (molt ràpid) |
